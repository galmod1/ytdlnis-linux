# YTDLnis Linux

نسخة لينكس من YTDLnis (أندرويد) — واجهة GTK4 فوق yt-dlp.
البرنامج الأصلي: https://github.com/deniscerri/ytdlnis — رخصة GNU GPL v3.

## التشغيل

```
~/projects/ytdlnis-linux/run.sh
```

أو من قائمة التطبيقات: **YTDLnis Linux**.

## المرحلة 1 — ما يعمل الآن

- لصق رابط أو عدة روابط (كل رابط في سطر) أو بحث مباشر (يُترجم إلى `ytsearch1:`)
- قوائم التشغيل: تُفكّ إلى عناصر مستقلة، مع صف للقائمة فيه زر «تحميل الكل» وعدّاد تقدّم (x/N مكتمل)
- صيغة واحدة للقائمة كلها: زر «الصيغة…» يطبّق الصيغة على جميع العناصر ويبدأها فوراً، وزر «إيقاف الكل» يوقفها لتغيير الصيغة ثم «تحميل الكل» يستأنف
- اختيار الصيغة: أفضل جودة، بحد 1080p أو 720p، صوت MP3/M4A، أو تنسيق محدّد من القائمة
- طابور تحميل مع تقدّم وسرعة ووقت متبقٍّ، تحميلات متزامنة (1–8) تُطبَّق فوراً بعد الحفظ
- محرّك اختياري aria2c بعدة اتصالات لكل ملف، وأجزاء متزامنة لتسريع البث المقطّع
- حدّ سرعة عام (KB/ث) يعمل مع المحرّك الداخلي ومع aria2c
- ثلاث لغات للواجهة: العربية، English، Français — تُختار من الإعدادات وتُطبَّق بعد إعادة التشغيل
- واجهة مقسّمة إلى أقسام حالة: قوائم التشغيل، جارٍ التحميل، في الانتظار، جاهزة، موقوفة، مكتملة، فاشلة، ملغاة، قيد الجلب — العناصر تنتقل تلقائياً بينها
- منتقي مجلدات داخلي لتغيير مسار الحفظ (بلا اعتماد على خدمات سطح المكتب) والمسار ظاهر في الشريط السفلي
- إيقاف مؤقت / متابعة (يستأنف من حيث توقف) / إلغاء / إعادة المحاولة
- تضمين الصورة والبيانات الوصفية، ترجمة اختيارية، إزالة SponsorBlock
- كوكيز المتصفح، بروكسي، ووسائط yt-dlp إضافية من الإعدادات
- مجلد حفظ وقالب اسم ملف قابلان للتغيير

## البنية

```
main.py            نقطة الدخول (Gtk.Application)
core/settings.py   الإعدادات (~/.config/ytdlnis-linux/config.json)
core/models.py     عنصر التحميل والأدوات المساعدة
core/ytdlp.py      أوامر yt-dlp وقراءة المعلومات
core/downloader.py الطابور والعمليات والتقدّم
ui/window.py       النافذة الرئيسية وصفوف التحميل
ui/dialogs.py      نافذة الصيغة والإعدادات
assets/style.css   تنسيقات
```
